## Jobs, accounting and retry interpretation

- `routers/generation.py:229` admits the owned job, reserves a version, persists job/options and Book budget, then dispatches. `job_service.py:66` owns durable active-job deduplication. Versioned requests, ownership/lease predicates and ready-version reuse already provide useful protection against duplicate work.
- `jobs/tasks.py:429` binds job, attempt, owner, course, version and budget into `ProviderCallContext`. `provider_usage.py:507` records reservation → dispatch → received/unknown state, provider response ID, model, tokens, actual reported cost and elapsed milliseconds. Integer nanodollars avoid float ledger drift. Unknown monetary outcomes retain the reservation and block further Book work.
- Book cap is 95,000,000 nanodollars = **$0.095 per logical version**, not an account credit balance. No end-user credit wallet/debit system was found in the reviewed generation path. Provider 402/credit exhaustion classification is separate from Book budget admission.
- Structured calls disable OpenAI SDK retries (`llm.py:215`); application loop allows two total attempts (`llm.py:334`). Budget/unknown-accounting errors, incomplete-length Book outputs, and specified permanent failures stop early. Embeddings use a distinct three-attempt policy; TTS uses another three-attempt policy. Documentation saying every call retries once is overbroad.
- Durable job retry/capacity continuation is a further layer (`jobs/tasks.py:304,350,487`). Report both job attempts and provider attempts. A retried job can reuse Book checkpoints; Video does not have equivalent partial-stage reuse.
- Per-job costs must come from `provider_calls.cost / 1e9`, grouped by job/attempt and model, with unknown rows shown separately. `provider_stages` supports queue/total and Book stage timing. TTS charges/CPU time are not represented as provider tokens or costs. Shared account before/after usage is only contextual evidence and must not be assigned to this review when concurrent jobs exist.
- Local provider-call exceptions are persisted safely in the ledger, but `llm.py:374` logs the full Pydantic validation exception; Pydantic errors can include portions of rejected input. Review log redaction separately before claiming that **all** logs contain no provider content. No leak was actively demonstrated here.

## Privacy payload scope and lifecycle limits

- Embeddings send retained source chunk text, not merely keywords. OCR sends selected page images. Course title sends a 4000-character source sample. Source planning sends selected raw chunks with source filenames/page numbers and internal chunk labels. Artifact generation sends assigned source evidence and canonical plan data. Video TTS sends narration text to Microsoft.
- Frontend receives sanitized public artifact/source views rather than raw provider traffic; prompt injection resistance is explicitly instructed in source-plan and chapter templates, but source content is combined in one user-role prompt (`llm.py:276`). This is a useful defense, not proof of resistance to all malicious documents.
- Cache identity uses a hashed course scope and complete text/model identity (`embedding_cache.py:23,45`), preventing intentional cross-course cache reuse. The vector cache has no removal method; `VectorStore.delete_course` only removes Chroma records (`vector_store.py:465`). Account/course cleanup should be checked for orphan cache retention before asserting complete deletion. Vector files are derived data even when they contain no raw text.
- Runtime OpenRouter account privacy settings, processor retention, storage encryption, deployment log access and actual export access behavior were not verified by this architecture subreview.

## Cost comparisons and candidate improvements

Rates checked from primary OpenRouter pages on 2026-09-06: [Gemini 2.5 Flash](https://openrouter.ai/google/gemini-2.5-flash) $0.30/M input and $2.50/M output; [Gemini 2.5 Pro](https://openrouter.ai/google/gemini-2.5-pro) $1.25/M input and $10/M output at the displayed base tier; [text-embedding-3-small](https://openrouter.ai/openai/text-embedding-3-small) $0.02/M tokens. These are list-rate references, not measured invoices; context tiers, routing, cached tokens and thinking change actual billing.

Illustrative **Video LLM-only** estimate: assuming each logical plan/script call uses 10,000 input + 4,000 total billable output tokens, a cold Pro plan+script costs $0.105; reusing an already paid matching plan leaves $0.0525 (50% marginal reduction under equal-sized-call assumptions). Flash at identical tokens would cost $0.026 for two calls or $0.013 for one (about 75.2% below the matching Pro scenario). This is arithmetic, not a quality or latency benchmark. TTS, CPU, retries, taxes, provider fees and cache pricing are excluded; no complete-Video savings claim is established.
